
# Aleximitation E-Commerce

A responsive e-commerce website built with HTML, Tailwind CSS,
JavaScript, and Firebase.

## Features

- Responsive storefront
- Product catalogue and search
- Shopping cart and wishlist
- Customer authentication
- Product and order management
- Admin dashboard
- Firebase Hosting and Cloud Firestore

## Technologies

- HTML5
- Tailwind CSS
- JavaScript
- Firebase Authentication
- Cloud Firestore
- Firebase Hosting

## Development

Install dependencies:

npm install

Build CSS:

npm run build:css

Deploy to Firebase:

firebase deploy --only hosting
